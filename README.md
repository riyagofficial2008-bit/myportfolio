# Riya Gupta — Portfolio

A futuristic, responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure/content
- `style.css` — design, animations and responsive layout
- `script.js` — theme toggle, custom cursor, AI console, modal and contact form
- `assets/profile.jpg` — profile photo

## Before publishing
1. Replace the `#` social links in `index.html` with your real GitHub, LinkedIn and Instagram URLs.
2. Replace `YOUR_EMAIL_HERE` in `index.html` and `script.js` with your real email.
3. Add your real resume PDF and change the site to link to it when ready.
4. Replace the three project concepts with your actual projects as you build them.

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.
